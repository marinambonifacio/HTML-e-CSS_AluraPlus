# Alura Plus
O projeto foi desenvolvido durante o curso de HTML e CSS: praticando HTML/CSS da Alura. O objetivo principal foi consolidar conhecimentos fundamentais de estruturação e estilização de páginas web, aprendendo boas práticas e design responsivo.

# 🛠️ Tecnologias Utilizadas
- HTML5: Estruturação semântica do conteúdo.
- CSS3: Estilização, layout e responsividade.

# 🧠 Aprendizados do Projeto
- Construir um site utilizando HTML e CSS
- Configuração e Workflow: Configuração de ambiente no VS Code, versionamento com GitHub e deploy via GitHub Pages e Vercel.
- Estrutura HTML Semântica: Uso de tags estruturais (head, section, footer), metadados essenciais e distinção funcional entre botões e links.
- Estilização Avançada: Criação de layouts com Flexbox e Grid, domínio do Box Model (margin, padding), responsividade com unidades em e interatividade com pseudo-classes (:hover).
- Design e Tipografia: Extração de elementos, estilos e assets do Figma, integração com Google Fonts e gerenciamento de cores e fontes.
- Boas Práticas: Organização de código com a metodologia BEM, uso de Variáveis CSS para escalabilidade e depuração via Ferramentas do Desenvolvedor (F12).
